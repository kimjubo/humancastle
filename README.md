# 아파트 분양 사이트 리디자인 데모 (디자인 예시)

> **디자인 예시용 데모입니다. 원본 사이트·시행사·시공사와 무관합니다.**
> 원본 사이트의 사진·로고·문구·코드는 사용하지 않았습니다. 단지명 "휴먼캐슬 하늘마루"와 모든 정보는 가상·더미이며, 사진은 Unsplash 무료 이미지(출처 `CREDITS.md`), 지도·평면은 직접 만든 SVG입니다.

- 구성: `index.html`, `style.css`, `script.js` (빌드 불필요)
- 로컬 실행: `python3 -m http.server 8000`
- 수정: 문구는 `index.html`에서 직접 수정. 색은 `style.css` 상단 `:root` 변수
- 문의 폼: `index.html`의 `YOUR_ACCESS_KEY`를 Web3Forms 키로 교체하면 동작 (현재 미연결)
- 분석: `docs/analysis.md`
- 비공개 저장소. 배포하지 않음.
- 사진 출처: `CREDITS.md`
